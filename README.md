# Labor artística y gestión cultural

Presentación web de Saga Barros. Esta versión contiene la apertura y el bloque 1, **Labor artística**. El bloque de gestión cultural se incorporará después.

## Uso

Abrí `index.html` en un navegador o visitá la página de GitHub Pages de este repositorio. Avanzá con las flechas del teclado, barra espaciadora o los botones. `O` abre el índice, `N` muestra las notas para exponer y `F` activa pantalla completa.

Las fuentes de las afirmaciones históricas, legales y sobre trabajo e IA están enlazadas en las notas de cada diapositiva. La fotografía de Saga Barros fue proporcionada por la persona usuaria.
